# 🎓 AI Student Assistant PRO

An advanced AI-powered student productivity platform built using **Python, Streamlit, SQLite, and OpenAI API**.  
Designed to help students with academics, planning, interview preparation, and daily productivity.

---

## 🚀 Live Features

### 🤖 AI Powered Tools
- Smart AI Chatbot for academic queries
- Voice Assistant (speech input + AI reply)
- PDF Notes Q&A (upload notes and ask questions)
- OCR Timetable Reader (extract text from timetable images)
- AI Exam Paper Generator
- Coding Interview Bot

### 📚 Student Productivity Tools
- Attendance Calculator
- Smart Study Planner
- Weekly Progress Dashboard
- Chat History Storage
- Export AI Responses to PDF

### 🔐 Authentication System
- Secure Login/Register
- Password hashing using bcrypt
- SQLite Database support
